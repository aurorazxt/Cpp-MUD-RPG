# Cpp-MUD-RPG
A console-based MUD game developed in C++ for the 2026 Summer Programming Fundamentals Practice course, featuring currency management, role development, battle simulation, and strategic decision-making systems.
游戏设计
玩家属性：生命值 攻击值 金钱 武器
怪物属性 生命值 攻击值 玩家可获得数值以及金币值
npc：玩家可获得道具以及武器
游戏可以一键显示玩家怪物以及npc的属性（玩家属性随时可以显示，npc和怪物属性到相应地点可以显示）
玩家可以选择攻击怪物（获得生命值以及攻击值上涨以及获得金币）或者逃跑
玩家可以选择帮助（获得道具或者武器）或者无视（等于逃跑）或者攻击（攻击成功获得“大幅度”数值提升以及道具或者武器，攻击失败直接死亡）
npc拥有生命值但不会给玩家显示（npc生命值高则玩家死亡，反之亦然）
玩家获得武器武器栏相应改变，并且攻击值增加
玩家一旦获取道具即可使用（道具的作用就是增加生命值和攻击值）
玩家可以使用金币在商店购买武器以及道具
人员 负责模块 核心产出 备注
A 命令解析和执行模块 完整命令解析器 + 命令路由表 + 游戏主循环 最核心，需最快出框架供其他人接入
B 地图与房间模块 20+房间连通图 + 房间描述 + 房间内物体管理接口 可提前设计一张"游戏世界地图"
C 玩家角色模块 玩家完整属性系统 + 背包管理 + 状态变化接口 包括升级公式、死亡处理
D 敌人角色模块 + 物品模块 10种敌人（含AI行为）+ 15种物品（含使用效果）+ 掉落表 数据量大，可配合B摆放
E 进度存档与读取模块 全量JSON存档 + 增量自动存档 + 读档恢复 需了解所有模块的数据结构
